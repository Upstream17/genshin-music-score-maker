# library/ — 成品示范与试听曲库

这里放置**人工挑选的成品示范曲谱**（共 **28 首**，直接位于本目录下），用于展示工具链的编曲输出形态，以及在部署到网页端时供访客直接试听。

## 曲目规格

由本项目工具链（及 AI 辅助编配/微调工作流）转换并验证的 **BetterGI 21 键 `midi` JSON**：

| 字段 | 说明 |
|---|---|
| `type` | 全部是 `midi`（`bpm:60` + `ticks:1000`，1 tick = 1 ms） |
| `author` | 原曲作者 / 转换署名元数据 |
| `description` | 记录了源文件背景、移调量、音符数、可演奏率、折叠/吸附数及局部微调细节 |

## 怎么用

- **在 BetterGI 中自动演奏**：BetterGI → 自动演奏 → 选择曲谱目录 → 指向本目录（`library/`）。目录里只放 `.json` 曲谱或注意忽略说明文件。
- **在网页演奏台试听/编辑**：HTTP(S) 在线访问网页端会自动加载本目录的 28 首示范曲；本地直接双击打开 `app/index.html` 时，可把 `library/` 或任意 `.json` 拖进页面。

## 自己生成新曲目

```bash
python skills/genshin-music-scores/scripts/score_cli.py convert "path/to/song.mid" --name "曲名" --outdir output
```
