# library/ — 可公开的曲谱

这里**只放能公开的曲谱**。含第三方作品改编的内容放在仓库外的 `library-private/`（已被 gitignore）。

## converted/

由本项目工具链从第三方来源（MIDI / 光遇 Sky 谱 / FF14 诗人谱等）转换成 **BetterGI 21 键 JSON** 的成品，
共 **47 首**。

| 字段 | 说明 |
|---|---|
| `type` | 全部是 `midi`（`bpm:60` + `ticks:1000`，1 tick = 1 ms） |
| `author` | `原作者 \| Hermes 转换`，原作者来自源文件元数据或公开资料 |
| `description` | 记录了源文件、移调量、音符数、可演奏率、折叠/吸附数等转换细节 |

### 版权状态（重要）

**这些曲谱的著作权属于原作者/权利方，不属于我们。**
我们把它们放进仓库，是为了演示工具链的输出形态、便于同好交流学习，
**不对其中的音乐作品主张任何权利**，也不提供任何商业授权。

转换本身不产生授权：把别人的 MIDI 换成 JSON，不会让这份音乐作品变成可自由分发的。
如果你认为某个文件侵犯了你的权益，开 Issue 说明，我们会直接删除。

想完全不承担风险？只用代码和工具，在你本机自己生成曲库（见根目录 README）。

## 怎么用

**给 BetterGI**：BetterGI → 自动演奏 → 选择曲谱目录 → 指向本目录（`library/`）。
它会递归扫描子目录，目录里只放 `.json`，别塞 README（会触发解析告警）。

**在网页里试听/编辑**：打开 `app/index.html`，把 `library/` 拖进页面。

## 怎么再加进来

```bash
# 单曲：任意源（.mid / .json / 光遇 .txt）→ 转换 → 强校验 → 入库
python tools/add_songs.py "路径/歌.mid" --name "曲名" --to ../library/converted
```

`add_songs.py` 默认写入 `library-private/05_我的新增/`；想放进可公开的 `library/`
就显式指定 `--to`，并自己确认这首的版权状态。
