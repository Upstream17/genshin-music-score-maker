    操作说明与快捷键

    1. 录制旋律（边播边录 / 按住随时间戳变长）

    • 点击 「● 录制」 开启或关闭录制模式（若未选曲目会自动新建空白曲谱）。
    • 边播放边录：点击「播放」后按键盘 Q~U / A~J / Z~M 或点击屏幕琴键即可实时录入；按住琴键不松，音符会随时间轴后移实时变长，松开即定格时值。
    • 暂停态录制：暂停时按住琴键不松并按 → 后移时间戳，音符同样会随时间戳实时拉长；直接轻按琴键则在当前时间戳落下一个音符。

    2. 方向键微调（时间戳 & 选中音符）

    • 未选中音符时（微调当前播放头时间戳）：
      ← / → 按当前「吸附」步长微调时间戳 · Alt+←/→ 按 10ms 极细微调 · Shift+←/→ 前后跳转 1 秒 · ↑ / ↓ 切换上一首 / 下一首。
    • 选中音符时（点击画布音符选中，按 Esc 取消选中）：
      ← / → 按「吸附」步长平移音符起点 · Alt+←/→ 按 10ms 微调起点 · Shift+←/→ 缩短 / 加长音符时值 · ↑ / ↓ 升降音高 · Delete 删除 · Ctrl+Z 撤销。

    3. 批量框选与时间轴表头剪辑（类 Excel 逻辑）

    • 主画布框选音符（类 Excel 选单元格）：在主画布网格空白处按住左键拖拽即可矩形框选多个音符（或 Shift+点击加减选、Ctrl+A 全选）。按住任一已选音符拖动可整组平移时间/音高，拖右边缘可批量调整时值，按 Delete 仅删除选中的音符（其他音符位置不变）。
    • 顶部时间轴拖选（类 Excel 选整列）：在上方时间轴表头按住左键横向拖拽，即可选中整个时间段空间（贯穿全列高亮）；此时按 Delete 或点击工具栏 「✂ 删时间段」，即可直接删掉这一整段时间（含空白与音符），并将后续所有音符自动整体前移填补。
    • 时间轴浏览与曲目管理：轻点顶部时间轴表头跳转进度，滚轮或右键拖拽平移时间轴（Ctrl+滚轮缩放窗口）；点击主标题或歌单项右侧 ✎ 内联改名，× 单独删除曲目。
